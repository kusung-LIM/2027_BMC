## 핵심 결론 세 줄

1. **가장 비싼 G1석(280,000원)이 이 기준표에서는 하위권입니다.** 공식 고지대로 플로어 G1·G2·G3는 "단차가 없는 평지"이므로 앞사람에 시야가 막히고 전시간 기립하게 됩니다.
2. **편안함까지 전부 잡으려면 1층 T1 / T2** (지정석 P, 250,000원) — 공식 고지에 "테이블이 부착된 테이블석"으로 명시된 유일한 구역입니다.
3. **시야를 1순위로 두고 음향·가성비까지 챙기려면 2층 E3 / E4** (지정석 S, 187,000원).

> **단, 등급은 기준에 종속됩니다.** 음향·편안함·가성비를 전부 제외하고 시야와 아티스트 근접만 보면 순위가 뒤집혀 **G1석 106(1열 정중앙)이 최상위**가 됩니다. [05번 문서](05-criteria-and-guide-ddojji.md) 참고.
